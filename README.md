# StorageIQ — Android Storage & File Organizer

A native Android storage management utility built around modern Scoped Storage and the Storage Access Framework (SAF), designed for offline file categorization and duplicate cleaning.

Part of the **[Stylix Developer Portfolio](https://stylixdev.vercel.app)** by **[@StylixXD](https://github.com/StylixXD)**.

---

## Highlights

- **Scoped Storage & SAF Native:** Fully compliant with modern Android storage restrictions (Android 11–15+), requiring zero broad storage permissions.
- **100% Offline & Private:** Zero network requests, zero telemetry, zero cloud tracking. Every scan and operation runs entirely local on-device.
- **Fast Content Hashing:** Byte-level duplicate detection using optimized checksum passes for large media, documents, and downloaded APKs.
- **Granular Storage Breakdown:** Instant visual breakdown of hidden space consumers, orphaned cache files, and residual app directories.

---

## Tech Stack

- **Platform:** Native Android (API 26+)
- **Language:** Kotlin
- **Architecture:** MVVM with Coroutines & Flow
- **Storage APIs:** DocumentFile, ContentResolver, Storage Access Framework
